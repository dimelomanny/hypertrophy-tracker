# Hypertrophy Tracker

A free, offline-capable workout tracker (installable web app) with a 5-day Push / Pull / Legs / Upper / Lower hypertrophy plan built for a Smith machine, dumbbells and a single cable stack. Exercise variations rotate across a 4-week cycle.

Features: YouTube tutorial search per exercise, front/back muscle diagram, set check-off with weight and reps, set/rest/session timers with a rest-done beep and flash, a live calorie estimate, session history, weekly sets-per-muscle chart, and JSON export/import of history.

No accounts or sign-in. All data stays in your browser's localStorage on your device.

Live app: https://dimelomanny.github.io/hypertrophy-tracker/

Install on iPhone: open the link in Safari, tap Share, then Add to Home Screen.

Plain HTML/CSS/JS, no build step. Calorie numbers are estimates (MET-based); nutrition notes are general guidance, not medical advice.
